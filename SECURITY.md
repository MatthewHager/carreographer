# Security

Carreographer runs entirely in your browser: no server, no accounts, nothing uploaded.
Only the live site and `main` are supported.

## Reporting

Please report privately: on the repository's **Security** tab, choose **Report a vulnerability**.
Don't open a public issue. I'll reply as soon as I can and credit you in the fix if you'd like.

## What counts

- Code running in the page from a song file, a link or a show file
- A tampered dependency, model or release file reaching the site
- A show that drives a car's liftgate, doors, windows, mirrors or charge port past Tesla's limits

How a show looks, and problems in Tesla's own software, aren't security issues: open a regular issue.
